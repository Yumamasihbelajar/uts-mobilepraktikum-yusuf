# Nusantara Coffee - Aplikasi Katalog Kopi Indonesia

## 📱 Deskripsi Aplikasi
Nusantara Coffee adalah aplikasi mobile yang dikembangkan menggunakan framework Flutter untuk menampilkan katalog kopi-kopi terbaik dari berbagai daerah di Indonesia. Aplikasi ini dirancang dengan antarmuka yang clean dan user-friendly.

## ✨ Fitur Utama
- **Halaman Beranda**: Tampilan awal dengan informasi aplikasi dan navigasi
- **Daftar Kopi**: Menampilkan daftar kopi dari berbagai daerah dengan data dari file JSON
- **Detail Kopi**: Informasi lengkap tentang setiap jenis kopi termasuk asal, kategori, harga, dan deskripsi

##  Struktur Halaman
1. **HomePage** (`/`) - Halaman beranda dengan banner dan tombol navigasi
2. **MenuPage** (`/menu`) - Halaman daftar kopi dengan data dari JSON
3. **DetailPage** (`/detail`) - Halaman detail informasi kopi
